# Набор полезных bash-скриптов

Этот репозиторий содержит коллекцию bash-скриптов для решения различных задач.

## 📋 Список скриптов

1. **[hello.sh](./hello.sh)** - Приветствие пользователя
   - Запрашивает имя и выводит приветствие

2. **[sum_calculator.sh](./sum_calculator.sh)** - Калькулятор суммы
   - Складывает два введенных числа

3. **[check_even.sh](./check_even.sh)** - Проверка четности числа
   - Определяет, является ли число четным или нечетным

4. **[project_creator.sh](./project_creator.sh)** - Создатель структуры проектов
   - Создает базовую структуру для веб-проекта

5. **[line_counter.sh](./line_counter.sh)** - Счетчик строк в файле
   - Подсчитывает количество строк в указанном файле

6. **[password_generator.sh](./password_generator.sh)** - Генератор паролей
   - Генерирует случайный пароль длиной 8 символов

7. **[file_finder.sh](./file_finder.sh)** - Поиск файлов
   - Ищет файлы по расширению в текущей директории

## 🚀 Использование

Для выполнения любого скрипта используйте команду:
```bash
sh имя_скрипта.sh
